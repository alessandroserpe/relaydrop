Accesso amministratore: dove trovo la credenziale?

È stata salvata in un file privato durante l’installazione, di solito chiamato admin-token. Recuperala dal tuo gestore di password oppure dal file indicato al termine dell’installazione.

Incolla il contenuto del file nel campo qui sopra. Con l’accesso amministrativo compare Impostazioni; con quello personale le preferenze sono in Dispositivi e avvisi.

Se non hai installato tu il servizio, chiedi la credenziale adatta a chi lo gestisce. Quella amministrativa va conservata separatamente da quella dei tuoi dispositivi.

Le chiavi dei file rimangono nei browser registrati. Cambiare accesso non elimina queste chiavi.

    I tuoi browser

    Per aggiungere un computer, apri questa casella sul computer, accedi con la stessa credenziale e registra il browser con un nome riconoscibile. Gli avvisi sono facoltativi. Le chiavi private vengono conservate solo su quel browser. I file già condivisi arrivano anche qui quando apri RelayDrop su un dispositivo che può già leggerli: le chiavi vengono sincronizzate in forma cifrata.

      Esci termina la sessione ma conserva le chiavi. Eliminare i dati del browser elimina anche le chiavi locali. Prima di rimuovere il tuo ultimo browser con accesso ai file, completa la sincronizzazione su un altro dispositivo. La rimozione di un browser impedisce i nuovi invii; non ritira chiavi già ricevute.

      Preparazione degli avvisi…

      RelayDrop sulla Home

      In Safari apri Condividi → Aggiungi alla schermata Home. Se compare l’opzione, lascia attivo “Apri come app web”. Poi apri l’icona RelayDrop, accedi e torna qui per attivare gli avvisi.

      La versione sulla Home può richiedere un nuovo accesso e registra una propria chiave. Servono iOS 16.4 o successivo e il permesso alle notifiche.

      L’avviso è generico e apre la tua casella. Nessun nome, riepilogo o chiave viene inviato nel messaggio. La consegna usa il servizio push del browser; su iPhone, Apple. Uscire dalla casella non disattiva gli avvisi.

      Riepiloghi privati

      Il tuo agente locale può generare il riepilogo prima dell’invio. Il browser lo decifra insieme ai dettagli; il server non lo legge. I riepiloghi AI possono contenere errori e vanno verificati sul documento.

      Limiti del servizio

      Valgono per i nuovi upload. Ridurli non elimina file esistenti. Le modifiche vengono salvate sul server.

      Questi file non hanno un limite di download e occupano spazio fino alla scadenza scelta o alla cancellazione manuale. Disattivare questa opzione non modifica i file già conservati. Le date scelte rispettano la durata massima.

      Il browser decifra in memoria: file grandi possono superare la capacità del telefono. La CLI cifra a flusso su un file temporaneo. Limite tecnico di questa versione: circa 2 GiB; validare ogni aumento sui dispositivi effettivi.
